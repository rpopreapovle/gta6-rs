# GTA VI — Rust Edition

> Grand Theft Auto VI, rewritten in Rust. 0.0.1-alpha.0.

A faithful reimplementation of the entire game. Currently: one mission, one
player, one very fast binary. Vice City is a `println!` away.

## Build & run

```bash
cargo run --release
```
